# 專案管理備查

本頁依專案歷程回顧整理，供 AIPM 期末評審對照人力分工、預算、風險與里程碑。4C 雲端試驗和 7A2 評比試用屬不同階段。

## 人力配置與分工

| 角色 | 有紀錄的工作 |
| --- | --- |
| 團隊與使用者 | 確認試用範圍與版本取捨，參與操作驗收及成果展示。 |
| Claude | 4C 網頁與語料整理。7A2 階段審閱指南導覽、回歸結果與發布交接。 |
| Codex | 獨立覆核、部署與雲端驗收。7A2 整合長照指南、執行瀏覽器回歸及核對安裝包。 |
| 專業與授權覆核角色 | 分別確認照護內容適用性與第三方素材使用範圍。 |

## 預算與用量

4C 的雲端試驗採合計每月 **NT$1,000** 的預算規劃。當時的紀錄中，查詢使用 19／75 次，內部預留 NT$38；建索引使用 254 次，內部預留 NT$127。這些數字用於控管試驗用量，實際費用以帳單為準。7A2 的現行問答走 NotebookLM 橋接流程，先前語氣改寫使用的 Cloud Run 服務已停用。

## 風險矩陣

| 風險 | 可能影響 | 已採措施或應對 |
| --- | --- | --- |
| NotebookLM 介面變動或引用讀取不完整 | 問答或引用擷取中斷 | 針對提問與部分引用做回歸測試。引用不完整時仍顯示原答。 |
| 語氣改寫變動引文 | 家屬可能把改寫文字讀成原文 | 試測以人工對照確認偏差，現版直接呈現 NotebookLM 原答。 |
| 評審環境和試用環境有差異 | 問答示範可能中斷 | 提供公開筆記本與擴充功能安裝說明。展示以同一 Chrome 設定檔操作，實測畫面可供備援。 |
| 第三方語料授權與回答適用性 | 限制素材提供範圍與照護使用 | 依授權提供原檔或來源連結，介面標明回答尚未經專家覆核。 |
| 地圖載入時快速切換清單 | 可能出現瀏覽器錯誤 | 展示時等地圖圖磚載入後再切換清單。 |
