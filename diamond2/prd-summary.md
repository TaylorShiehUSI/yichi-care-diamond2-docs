# 產品需求摘要

第一個鑽石聚焦剛接手失智照顧的家屬。遇到照護問題時，家屬希望能用自己的話提問、理解可採取的下一步並核對依據。商業價值假設是減少找資訊與辨識申辦入口的時間，可用完成任務的比例與時間驗證。

| 需求 | 7A2 的實作範圍 |
| --- | --- |
| P1 情境提問 | 試用頁透過 Chrome 擴充功能向指定 NotebookLM 筆記本提問。 |
| P2 核對來源 | 單欄呈現最新 NotebookLM 原答及可取得的引用。 |
| P3 資源導航 | 資源查詢新增長照費用與申請準備卡，可開啟團隊指南並返回。 |

本頁依《憶起照顧 V0.3 產品需求與系統規劃 審查草案》及 2026 年 11 月 16 日 7A2 交接紀錄回顧整理。V0.3 涵蓋更廣的照護導航構想，表中列出本次評比試用版的交付範圍。
